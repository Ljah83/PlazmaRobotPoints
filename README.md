1. Запустить в терминале uv run main.py, находясь в директории проекта
2. Выбрать плазму, файл dxf или cnc(предпочтительней) из pronest, настройки и нажать "Рассчитать".
3. Сформируется файл circles_centers.txt в формате ABB Rapid с координатами центров окружностей содержащихся в файле.
4. При нажатии выход внесённые настройки не сохраняются.

Примечание для импорта CNC файлов:
1. Расширение должно быть CNC не txt.
2. При рассчёте применяется дополнительное смещение. Необходимо для листов лежащих на других упорах. Если выбраны координаты смещения, то корректировку начального положения и положения применения отскока дополнительной оси вычислять самостоятельно.
3. 

Примечания для импорта dxf файлов:
1. Горизонтальная ось принимается равной Y, вертикальная X.
2. Координатная ось дополнительной оси робота 1ой плазмы отсчитывается от кантователя, 2ой плазмы от контроллера робота.
3. Дополнительное смещение системы координат не применяется.
